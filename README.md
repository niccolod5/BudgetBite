# BudgetBite

App per spesa, dispensa, pranzi e cene della settimana, budget ed extra.
È un sito statico: basta pubblicare questa cartella così com'è (per esempio con GitHub Pages) e aprirla in Safari.

## Installazione su iPhone
1. Apri l'indirizzo del sito in Safari.
2. Condividi, poi "Aggiungi alla schermata Home".

## File
- index.html: l'app completa
- manifest.webmanifest, icon-*.png: nome e icona per la schermata Home
- sw.js: permette all'app di aprirsi anche senza internet

I dati restano salvati sul telefono. Per conservarli o spostarli usa Opzioni, poi Dati, poi "Copia il backup".
